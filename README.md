Welcome to my active portfolio repository. This project represents my approach to building accessible, privacy-respecting, and thoughtfully crafted web experiences. It is designed with a distinct aesthetic while maintaining strict adherence to semantic HTML, responsive CSS, and local-first principles.

## 🌌 Project Overview

This portfolio is a static website built from the ground up using core web technologies. It avoids heavy frameworks in favor of lightweight, understandable, and highly performant code. 

### Key Features
- **Responsive & Fluid Design**: Utilizes CSS Grid, Flexbox, and `clamp()` for seamless adaptation across all device sizes without excessive media queries.
- **Thematic Aesthetic**: A custom "Gothic Cyberpunk" design system featuring CSS variables for easy theming, neon accents, and subtle, performant animations.
- **Privacy-First Philosophy**: No tracking scripts, no external analytics, and no unnecessary third-party dependencies. 
- **Optimized Deployment**: Configured for rapid, secure, and free deployment via Firebase Hosting.
